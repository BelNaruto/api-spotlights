# Sports Information API

**Scores, stats, standings, odds and predictions for 90+ leagues**

One API for live scores, schedules, standings, box scores, play-by-play, odds, injuries, rosters, player stats, news and game predictions across NBA, NFL, MLB, NHL, college sports, soccer, tennis, motorsport, golf, MMA and more.

[**Try it on RapidAPI**](https://rapidapi.com/belchiorarkad-FqvHs2EDOtP/api/sports-information) · [Telegram support: @pintoflow](https://t.me/pintoflow)

## What you get

- Scoreboards, schedules and live games
- Box scores, play-by-play and win probability
- Standings, teams, rosters and injuries
- Player profiles, game logs and splits
- Odds, futures and model predictions
- 41 sports and 900+ endpoints in one consistent envelope

## Popular use cases

- Fantasy sports apps
- Betting and odds tools
- Sports media automation
- Analytics and prediction models
