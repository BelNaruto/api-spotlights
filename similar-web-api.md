# Similar Web API

**Website traffic and competitive intelligence data for any domain**

Get SimilarWeb-style analytics for any website through a simple REST API: traffic estimates, engagement, traffic sources, keywords, referrers, audience interests and competitors.

[**Try it on RapidAPI**](https://rapidapi.com/belchiorarkad-FqvHs2EDOtP/api/similar-web-api) · [Telegram support: @pintoflow](https://t.me/pintoflow)

## What you get

- Domain overview and traffic estimates
- Engagement metrics
- Social and referral traffic, top referrers and referring industries
- Top organic keywords and paid search
- Top link and ad destinations
- Audience interests
- Competitor lists

## Popular use cases

- Market research and due diligence
- Sales and lead scoring
- SEO and SEM tools
- Data enrichment for CRM and BI

## Quick start

1. Subscribe to the free BASIC plan on [RapidAPI](https://rapidapi.com/belchiorarkad-FqvHs2EDOtP/api/similar-web-api).
2. Copy your `X-RapidAPI-Key`.
3. Make your first request:

```bash
curl --request GET \
  --url 'https://similar-web-api.p.rapidapi.com/domain/traffic?url=example.com' \
  --header 'X-RapidAPI-Key: YOUR_RAPIDAPI_KEY' \
  --header 'X-RapidAPI-Host: similar-web-api.p.rapidapi.com'
```
